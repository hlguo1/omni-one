9. How to use (60-second SOP)

  1. In the Close PWA press “Download close.csv” (or copy close.json from the API).
  2. Here: drop the file above or paste it, then “Parse + render”.
  3. Read validation first — red errors block sign-off (notably V1_PROFIT_GT_GMV).
  4. Walk the P&L bars: GMV → fees → shipping → COGS → profit.
  5. Check the fee table: if the shop “costs extra” vs Shopify, flag fee creep to the seller.
  6. Work the 6-step checklist (persists per date), then Print → PDF.
