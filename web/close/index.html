❓ Help · API contract · Shortcuts

API contract (same-origin)

POST /api/v1/seller/close body {"demo": true, "seed": 42, "shop": "our shop"} or {"folder": "/tmp/my_shop", "shop": "…"}. Returns close.json bundle: headline, kpis, do_today[3], reorder_sheet[], reply_queue[], money_leaks[], listing_fixes[], po_draft, ingest_report.
GET /api/v1/seller/close.csv?demo=true&seed=42&shop=… returns accountant-ready CSV. [index.html:api-contract]

Keyboard shortcuts
1…6 Today / Reorder+PO / Replies / Leaks / Listings / Files

c Download CSV (GET close.csv)
p Print / Save as PDF
/ Focus search in current tab
←→ Prev / next tab (when tab focused)

Full list in web/close/README.md. [index.html:shortcuts]

Print flow (accountant / fridge)

Open Today tab → Print (or p) → Save as PDF. Buttons, tabs and search hide in print; tables, reply drafts, PO and citations stay. File: web/close/index.html @media print. [index.html:print-flow]

Offline + cache (24h)

Service worker sw.js (CLOSE_V1, cache-first) keeps the shell offline. Last close is cached in localStorage close_last (24h) and shown with a banner when offline. No CDN — works with WiFi off. [sw.js:CLOSE_V1] [app.js:cache]

Citations everywhere (audit)

Every KPI, reorder row, reply, leak and fix shows file:line like [shopify_orders.csv:5], [inventory.csv:2], [reviews.csv:3], [instagram_dm.txt:1]. Raw JSON in Files tab is the audit trail. [index.html:citations]
