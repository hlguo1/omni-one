# 09 — 从电子表格迁移（周末切换）

周五：把所有表格（订单、库存、打款）导出为 CSV 放进 `./data/inbox`。
不要清洗——解析器能处理怪异表头、分号、BOM、多币种。

周六：`omni-one close --folder ./data/inbox --out ./close_first`。只跟你的表格对一个数：
GMV。差异 >1% 就去看 `ingest_report.errors`，或你的表格剔除而我们保留的退款行
（先查 `order_refund` 信号）。

周日：发出第一封 `po.txt`，回复前 3 个草稿，把 `close.csv` 连同字段字典
（`docs/handbook/04-accountant-pack.md`）交给会计。从周一开始：5 分钟结算替代表格。
旧表只读保留 30 天，然后归档。

不迁移的东西：透视表玄学、颜色标记的直觉、“调整后”GMV。引不出 `file:line` 的数字，
一律不带过来。
