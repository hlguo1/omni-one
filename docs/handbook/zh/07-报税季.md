# 07 — 报税季手册（见会计师时带上）

带上：12 × `close.json` + `close.csv` + `reorder.csv` + 本清单。

1. 损益勾稽：12 个月 `true_profit` 之和 == 全年利润。 margin < 0 的月份用 `money_leaks`
   写一句话原因（fee_creep/shipping_loss/margin_dip/cogs_spike）。
2. 成本证明：供应商发票（`supplier_invoice*`）+ OCR + 单位成本目录。标出用了
   30%-of-GMV 兜底（无发票）的月份。
3. 佣金：各渠道实付 vs 费率（Shopify 2.9%+30c、Etsy 6.5%+20c、Amazon 15%、
   TikTok 5%+30c、eBay 13.25%+30c）。把 fee_creep 行作为差异解释附件。
4. 退款：统计 `REFUND_RISK` + `order_refund`，与打款借项勾稽。没有引用就没有发生。
5. 库存：`on_hand` × 单位成本 = 资产负债表库存。`DEAD_STOCK` 清单支持减值。
6. 打包：`accountant_pack` → 一年一个 ZIP，内附清单。

红线：不编数字（一切引用 `file:line`）、不手工改 CSV（用 `omni-one close` 重生成）、
月份不缺（cron `7am-close.cron`）。
