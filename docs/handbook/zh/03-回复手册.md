# 回复手册 — 20 个复制粘贴模板 + 退款决策树

> 速度 + 温度 + 证据。结账生成的每条草稿自带
> `[file:line]` 引用——发出时保留（客户信收据）。只个性化**一句**；
> P0 **2 小时内**发出。
>
> `replies.txt` 优先级：`P0-reply-in-2h`（退款/未到/破损/chargeback 词）
> vs `P1-today`（其他）。
>
> 底部 i18n 提示：同样 20 个模板任何语言通用——
> 只需翻译开头和承诺句（第 7 节）。

## 退款决策树（先读这个）

```
客户不高兴？
├─ 从未到货 + tracking 死掉 > 5 天？
│   └─ 是 → 立刻重发 + 退运费。模板 03。（成本 ~1 个 AOV，保住评价。）
├─ 到货破损/不良 + 有照片？
│   └─ 是 → 给选择：免费补发 OR 全额退款。模板 05/06。（选择能灭火。）
├─ “我的订单在哪？” + tracking 还活着？
│   └─ 是 → tracking 链接 + 新 ETA + 10% 券。模板 02。（多数到此结束。）
├─ 要退款，货没问题，在退货期内？
│   └─ 是 → 接受，便宜就给预付单。模板 09。（硬扛更贵：手续费 + 时间。）
├─ 要退款，超期/已用/后悔 + 公开威胁（chargeback/1 星）？
│   └─ 也许 → 部分退款（30-50%）表心意。模板 10。（比 chargeback 手续费便宜。）
└─ 辱骂/欺诈信号（本月第 3 次“没到”、空照片、地址游戏）？
    └─ 是 → 礼貌坚定拒绝 + 证据。模板 12。（全部留档；该吃的差评就吃。）
```

**金钱规则：** 1 个 AOV 的退款 < 1 条 1 星差评（压转化好几个月），
远 < 1 笔 chargeback（$15–25 手续费 + 照样退款）。拿不准就退。

## 晚到/丢件（模板 01–04）

**01 — 晚了，tracking 还活着（P1）**
> 你好 {name}！谢谢耐心——我刚查了你的订单
> （{citation}），tracking 显示 {date} 前到。我会亲自盯着，
> 一到就告诉你。—— {shop}

**02 — 还没有 tracking（P0）**
> 你好 {name}！很抱歉 tracking 一直没出来——我刚查了
> 你的订单（{citation}），正在找承运商确认。
> 2 小时内给你 tracking + 新 ETA（卡住就解决：重发/退款你选）。感谢
> 你对 {shop} 的耐心！

**03 — 从未到，tracking 死了（P0）**
> 你好 {name}！不该让你追这件事——我今天就重发你的
> {product}，走 tracked，并退你原来运费
> （${x}）。新 tracking 今晚到你邮箱。（{citation}）
> 真的很抱歉让你等。—— {shop}

**04 — 显示签收但没收到（P0）**
> 你好 {name}！承运商显示签收但你没收到
> （{citation}）——误扫常有。我已开承运商追踪
> 并同步准备重发；48h 还没冒出来就自动发出替换件。{date} 前确认。—— {shop}

> 留着吧（或送人！），正确的 {product} 今天发出；tracking
> 今晚到。要退款也行。搞错了抱歉！—— {shop}

**07 — 质量投诉，还没照片（P1）**
> 你好 {name}！抱歉 {product} 没达到预期（{citation}）。
> 能拍张照片吗？一看到我就安排补发或退款——
> 小件不用退回。—— {shop}

**08 — 刚落一条差评（P0，公开回）**
> 感谢指出（{citation}）——很抱歉你的
> {product} 体验不好。造成这次的打包/品控我们已修好。

## 时效 SLA

| 优先级 | 首回 | 解决目标 | 负责人 |
|---|---|---|---|
| P0（退款/破损/未到/chargeback 词） | < 2h，7 天 | 24h | 你，亲自 |
| P1（咨询、地址、表扬） | 当天 | 48h | 你或帮手 |
| ≤ 2★ 评价 | 公开回 < 24h + 私信 < 1h | 72h | 你 |

批量技巧：每天两个 15 分钟 inbox 块（晨间结账 + 晚上）
加 P0 推送。P0 活不过晚间块。

## 语气规则（5 条）
1. 叫名字。永远不要“亲爱的顾客”。
2. 道歉一次，然后行动。不要三次道歉零方案。
3. 给时间（“2 小时内”“今晚”“周五前”），然后提前做到。
4. 给*选择*（重发/退款）——选择还给人掌控感。
5. 保留引用。发送前其他都可以删，证据必须留。

## i18n 提示
- 模板 01–04、08：先翻开头 + 时间承诺（它们承载 SLA）。
- 德/法/日买家：对方随便前保持正式（Sie/vous/です）。
- 西/葡语：“reembolso / reenvío”必须原文出现——买家会搜这个词。
- CJK + emoji 名：永远不要弄坏（原样复制；结账字节级保留——见 property 测试）。
- RTL（阿/希伯来）：引用单独放一行，避免 bidi 断裂。
- *模板*机翻，*承诺句*手改。语言对了日期错了照样丢客户。
