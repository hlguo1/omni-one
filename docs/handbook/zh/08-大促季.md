# 08 — 大促季手册（假期、促销、爆单）

1. 提前两周：畅销款 `COVER_DAYS` 14 → 21，供应商交期书面确认。
2. 大促期间每天结算两次（早 7 点 + 晚 7 点）。回复 SLA 2h → 1h；超过 4h 的
   `UNANSWERED_COMPLAINT` 就是一笔退款——按退款处理。
3. 价格冻结：除非 `PRICE_MISMATCH` 触发，否则不动价；要调就向上对齐，绝不向下竞价。
   原因记入 `close.json`。
4. 滞销款变搭售：`DEAD_STOCK` 与爆款打包 85 折，而不是给爆款打折。
5. 现金：大促 GMV 会骗人（退款滞后 7–14 天）。看 `money_at_risk_usd` 而不是 GMV。
   留 20% `true_profit` 作退款准备金，等退货尘埃落定。
6. 复盘：一次 retro 结算（`--out ./close_peak_retro`）——最大漏损、最慢回复、最惨缺货，
   下次大促前只调一个参数。
