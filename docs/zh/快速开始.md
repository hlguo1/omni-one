# 快速开始（60 秒，$0）

> 目标：一分钟从零进入每日结算仪式。
> 无需绑卡、无需联网、无需付费 LLM。全本地，`SELLER_LLM=mock`。

## 前置要求

- Python 3.10+ 和 `pip`。
- 已安装 `git`。
- 2 分钟终端时间。起步不需要 Docker。

## 60 秒安装

```bash
git clone https://github.com/garyguo123456789/omni-one.git && cd omni-one
pip install -r requirements-seller.txt && pip install -e .
omni-one doctor                                        # deps + pipeline smoke
omni-one close --demo --out ./close_today             # THE ritual: profit + reorders + replies
cat ./close_today/replies.txt                         # copy-paste a draft, send the PO
```

刚才发生了什么：

- `pip install -r requirements-seller.txt` 只装卖家必需的轻量依赖。
- `pip install -e .` 把 `omni-one` 命令暴露到 `PATH`。
- `omni-one doctor` 检查环境 + 依赖 + pipeline 冒烟。
- `omni-one close --demo` 用内置黄金演示店生成结算包。
- `cat ./close_today/replies.txt` 显示可直接复制粘贴的草稿。

## 你的店铺（真实文件夹）

```bash
mkdir -p /tmp/my_shop
cp ~/Downloads/*orders*.csv ~/Downloads/inventory.csv /tmp/my_shop/
cp examples/my_shop_template/*.csv /tmp/my_shop/   # fill blanks if needed
omni-one close --folder /tmp/my_shop --out ./close_2026-10-11 --shop "Maya's Handmade"
```

文件夹说明：

- 原样丢入导出：`shopify_orders.csv`、`etsy_settlement.csv`、`amazon_*.csv`。
- 加上 `inventory.csv`，保留 `supplier` 列。
- 加上 `reviews.csv`、`instagram_dm.txt` 或 `tiktok_dm.json`。
- 加上发票 `supplier_invoice.jpg/png/pdf/txt`（OCR + 侧车 `.jpg.txt`）。
- 订单命名为 `shopify_*`、`etsy_*`、`amazon_*`，渠道识别最准。
- Sniffer 支持 `;` 分隔和 BOM（`UTF-8-SIG`）。
- 匹配是模糊的（`Tote` ≈ `Tote Bag Handmade`），但完全同名最保险。

## 服务器 + SDK + 机器人

```bash
omni-one serve --port 5003 &                            # docs at /api/docs
PYTHONPATH=src python3 examples/sdk_demo.py
PYTHONPATH=src python3 examples/daily_close_demo.py
```

细节：

- API Base：`http://localhost:5003`。文档：`/api/docs`。
- 健康检查：`/health`、`/readiness`、`/status`、`/ping`。指标：`/metrics`。
- SDK 用 `from omni_one.client import OmniOneClient`。
- 示例：`OmniOneClient.local().close(demo=True)["headline"]`。
- 18 个路由见 `docs/API.md`，9 个命令见 `docs/CLI.md`。

## 故障排查

| 症状 | 原因 | 修法 |
|---|---|---|
| `omni-one: command not found` | 没跑 `pip install -e .` | 重跑 `pip install -e .` |
| 利润奇怪 | 缺发票或名字不一致 | 补发票；产品改成同名 |
| `;` 的 CSV 为空 | 本地导出 | 已支持；检查 UTF-8 |
| 乱码 `ï»¿` | Excel BOM | 已支持（`UTF-8-SIG`） |
