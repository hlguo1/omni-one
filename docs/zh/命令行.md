# 命令行

> 一个二进制，九个命令，零摩擦。全离线，默认 $0。
> 免安装替代：`PYTHONPATH=src python3 -m omni_one.cli ...`。

## 用法

`omni-one` (after `pip install -e .`) or `PYTHONPATH=src python3 -m omni_one.cli ...`.

最小安装：

```bash
pip install -r requirements-seller.txt && pip install -e .
omni-one doctor
```

## 命令表

| Command | What |
|---|---|
| `omni-one doctor` | env + deps + pipeline smoke |
| `omni-one demo` | Seller demo briefing |
| `omni-one briefing --demo --json b.json` | briefing; `--folder /p` for real shop |
| `omni-one scenarios --demo` | 12 scenarios ranked |
| `omni-one operations` | full ontology→workshop→AIP→audit loop |
| `omni-one close --demo --out ./close_today` | **Daily Close bundle** (json/csv/reorder/replies/po) |
| `omni-one export --demo --out briefing.csv` | briefing CSV |
| `omni-one serve --port 5003` | API server |
| `omni-one evaluate --n 500` | eval harness |

`make demo|close|test|e2e|serve|docker|lint|doctor` wraps the same.

## 逐条中文说明

- `omni-one doctor`：检查环境、依赖和 pipeline 冒烟。装完先跑它，出问题先贴它的输出。
- `omni-one demo`：用黄金数据展示卖家简报（`Profit $169.09`）。
- `omni-one briefing --demo --json b.json`：生成简报；`--folder /p` 指向真实店铺（`~/my_shop`、` /tmp/my_shop`）。
- `omni-one scenarios --demo`：把 12 个场景（断货、退款、费率等）按严重度排序。
- `omni-one operations`：跑完整 本体→工作台→AIP→审计 循环，无幻觉（`Product:*` + `stable_id`）。
- `omni-one close --demo --out ./close_today`：**仪式本身**。写出 `close.json` + `close.csv` + `reorder.csv` + `replies.txt` + `po.txt`。
- `omni-one export --demo --out briefing.csv`：导出简报 CSV，给表格/会计。
- `omni-one serve --port 5003`：在 `http://localhost:5003` 起 API（文档 `/api/docs`）。
- `omni-one evaluate --n 500`：用 N 条记录跑评测框架（实时指标）。

## 可复制配方

用真实店铺跑每日仪式：

```bash
omni-one close --folder ~/my_shop --out ./close_today
cat ./close_today/replies.txt
```

黄金演示 + 简报落盘：

```bash
omni-one close --demo --out ./close_today
omni-one briefing --demo --json b.json
omni-one scenarios --demo
```

服务器 + 冒烟：

```bash
omni-one serve --port 5003 &
curl -sf http://localhost:5003/health
PYTHONPATH=src python3 examples/sdk_demo.py
PYTHONPATH=src python3 examples/daily_close_demo.py
```

7 点 cron（自动结账）：

```cron
0 7 * * * cd /path/to/omni-one && PYTHONPATH=src python3 -m omni_one.cli close --folder ./data/inbox --out ./close_$(date +\%F) >> ./close_cron.log 2>&1
```

## 常用参数

| 参数 | 含义 | 示例 |
|---|---|---|
| `--demo` | 内置演示数据 | `omni-one close --demo --out ./close_today` |
| `--folder /p` | 真实店铺文件夹 | `omni-one close --folder /tmp/my_shop --out ./close_2026-10-11` |
| `--out ./dir` | 输出目录 | `omni-one export --demo --out briefing.csv` |
| `--shop "Name"` | 显示名 | `omni-one close --folder /tmp/my_shop --out ./close_2026-10-11 --shop "Maya's Handmade"` |
| `--json b.json` | JSON 输出 | `omni-one briefing --demo --json b.json` |
| `--port 5003` | API 端口 | `omni-one serve --port 5003` |
| `--n 500` | 评测记录数 | `omni-one evaluate --n 500` |
